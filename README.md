# Sufra-AI

Sufra-AI is a full-stack AI chat application built with React, Node.js, Express, MongoDB, and Mistral AI. The app allows users to sign in with Google, start AI-powered conversations, receive streaming responses in real time, and store chat history securely in MongoDB.

This project demonstrates full-stack development, authentication, protected APIs, AI model integration, real-time response streaming, and production-ready deployment configuration.

## Features

- Google OAuth authentication
- JWT-based authentication using HTTP-only cookies
- AI chat interface with real-time streaming responses
- Automatic chat title generation
- Persistent chat history with MongoDB
- Protected backend routes
- Responsive React/Vite frontend
- Production-ready environment configuration

## Tech Stack

**Frontend:** React, Vite, Tailwind CSS, Redux Toolkit  
**Backend:** Node.js, Express.js, Passport.js, JWT  
**Database:** MongoDB, Mongoose  
**AI Integration:** Mistral AI with LangChain  
**Deployment:** Render / Vercel-ready configuration

## Project Purpose

Sufra-AI was built as a portfolio project to showcase practical full-stack skills, including authentication, database integration, AI API usage, streaming responses, and cloud deployment.
